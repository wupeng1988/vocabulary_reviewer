## 1. 这是什么？我需要装东西吗？

**不需要。** 这是一个「本地背单词」小程序，所有数据只存在你自己的电脑里，不联网上传。

下载解压后你会看到这样一个文件夹：

```
WordReviewPro-1.0.0-macos-arm64/
├── Start.command       ← macOS 双击这个启动
├── start.bat           ← Windows 双击这个启动
├── start.sh            ← 终端启动用（一般用不到）
├── WordReviewPro.jar   ← 程序本体
├── jre/                ← 内置的 Java 运行环境
├── application.properties ← 配置文件（想换端口就改它，见第 4 章）
├── README.txt          ← 一页纸速查版（记事本能直接打开）
└── README.md           ← 就是这份详细文档
```

**`WordReviewPro.jar` 和 `jre/` 千万别删。**
删掉 `jre/` 的话，你电脑上就必须另外装 Java 才能跑。

**你唯一要做的事：双击启动文件。**

## 2. 解压

### macOS

1. 双击 `WordReviewPro-1.0.0-macos-arm64.zip`，系统会自动解压
2. 得到同名文件夹，**把整个文件夹拖到你喜欢的位置**（桌面、文稿都行）
3. 别只把里面的几个文件单独拖出来 —— 文件夹里的东西是配套的

### Windows

1. 右键 zip 文件 → **「全部解压缩」**（或「解压到当前文件夹」）
2. 得到同名文件夹，建议放到 `D:\` 或桌面
3. **不要在压缩包窗口里直接双击 `start.bat`** —— 那是解压到临时目录运行的，很容易出问题

> ⚠️ 移动、改名都没关系，**但请整个文件夹一起移动**，别把里面的文件拆散。

## 3. 启动（最关键）

### macOS 用户

双击 **`Start.command`**。

**第一次双击如果弹出这个提示：**

> 「Start.command」无法打开，因为它来自身份不明的开发者

按下面任一方法处理（只需做一次）：

- **方法 A（最简单）**：右键点击 `Start.command` → 选「打开」→ 再点「打开」
- **方法 B（命令行）**：打开「终端」App，粘贴下面这行后回车（把路径换成你的实际路径）：
  ```
  xattr -cr ~/Desktop/WordReviewPro-1.0.0-macos-arm64
  ```
  之后就能正常双击了

### Windows 用户

双击 **`start.bat`**。

**如果弹出蓝色的「Windows 已保护你的电脑」**（SmartScreen）：

1. 点左下角的 **「更多信息」**
2. 点 **「仍要运行」**

**如果弹出防火墙提示**（「Windows 防火墙已阻止…」）：
直接点 **取消** 就行 —— 我们只在本机使用，不需要别人访问，取消不影响任何功能。

### 启动成功的标志

启动窗口里会出现：

```
✅ 启动成功！
🌐 浏览器即将打开 http://localhost:8080
```

同时浏览器会自动打开 **http://localhost:8080**，看到页面就是成功了。

- **第一次启动会慢一些**（约 5～20 秒），耐心等窗口里的进度
- 启动后**别关那个黑窗口 / 白色终端窗口**，关了程序就停了
- 想停止程序：macOS 按 `Ctrl + C`，Windows 按任意键或直接关窗口

### 浏览器没自动打开？

手动打开浏览器，在地址栏输入：

```
http://localhost:8080
```

回车即可。注意是 **8080**，不是 5173（那是开发用的，你用不到）。
如果你改过端口（见第 4 章），地址里的 8080 也要换成你设的那个数。

## 4. 怎么改端口（可选）

默认端口是 **8080**。一般**不用改**，只有两种情况才需要动它：

- 启动时报「端口 8080 已被占用」，而占用它的**不是**本程序
- 你想换个顺手的地址

### 改法（3 步）

**第 1 步：打开配置文件 `application.properties`**

它就在程序文件夹里，和 `WordReviewPro.jar` 挨着：

- **macOS**：右键 → 打开方式 → 「文本编辑」
- **Windows**：右键 → 打开方式 → 「记事本」

**第 2 步：改最后一行**

翻到文件末尾，把 `8080` 改成别的数字，比如 `8081`：

```properties
server.port=8081
```

> 格式必须保持 `server.port=` 后面**紧跟数字**，等号前后不要加空格。

**第 3 步：保存 → 关掉程序 → 重新启动**

双击 `Start.command`（macOS）或 `start.bat`（Windows）。

⚠️ **浏览器地址也要跟着改**，改成 `http://localhost:8081`，否则会打不开。

### 改端口常见疑问

| 问题 | 回答 |
|:--|:--|
| 改完数据会丢吗？ | **不会**。端口和数据完全无关，数据在 `worddb.mv.db` 里 |
| 要改别的文件吗？ | **不用**。启动脚本会自动读取 `application.properties` |
| 必须重启吗？ | **必须**。关掉程序重新启动才生效 |
| 用什么端口好？ | 建议 `8081`、`8082`、`8888` 这类不常用的，范围 1～65535 |
| 改坏了怎么办？ | 把那行改回 `server.port=8080` 保存，重启即可 |
| 新端口还是被占？ | 换个数字再试，或先关掉占用那个端口的程序 |
| 程序提示「端口 8080 已被占用」 | 先确认是不是**自己重复双击了**（见第 8 章）；确实被别的软件占了，就按上面改端口 |

## 5. 第一次使用：导入你的单词

刚启动时词库是**空的**，这是正常的。三步导入：

### 第 1 步：新建词组（可选，但推荐）

1. 左侧菜单点 **「词组管理」**
2. 点 **「➕ 新增根词组」**，填个名字，比如 `IELTS 核心词`
3. 点「保存」

> 不新建也行，程序自带一个 **「默认词组」**，导入时选它即可。

### 第 2 步：导入 Excel

1. 左侧菜单点 **「数据管理」**
2. **先在「导入到词组：」选一个词组**（必选，不选无法上传）
3. 点击下方虚线框 **「将 Excel 文件拖到此处，或 点击上传」**
4. 选好 `.xlsx` 或 `.xls` 后**自动开始导入**，成功会有提示

### Excel 格式（A～E 列，必须对上）

| 列 | 内容 | 举例 |
|:--|:--|:--|
| **A** | 生词 | abandon |
| **B** | 音标 | /əˈbændən/ |
| **C** | 含义 | v. 放弃，抛弃 |
| **D** | 例句 | He abandoned his car in the snow. |
| **E** | 例句释义 | 他把车丢弃在雪地里。 |

- 第 1 行是标题行，照抄上面这 5 个标题即可
- 空行会自动跳过
- 不想自己做？先到「数据管理」点 **「导出为 Excel」**，会得到一个格式正确的空模板，照着填就行
- 同一个单词重复导入 = 更新内容，**不会重复添加，也不会清空你已有的复习记录**

### 第 3 步：开始复习

左侧菜单点 **「复习中心」** → 选一种模式 → 开始。

| 模式 | 干什么 |
|:--|:--|
| 完整复习（认读+拼写+默写） | 认读 → 拼写 → 默写，最全面 |
| 仅认读复习 | 只看英文想中文，刷眼熟 |
| 仅拼写练习 | 显示全部信息照着拼 |
| 仅默写复习 | 看中文默写英文 |
| 仅听音默写 | 只放发音写单词（需先有音频） |

> 📌 **单词发音（🔊）第一次播需要联网**，程序会去网上合成语音并缓存到本地。
> 导入大批单词后，程序会在后台陆续生成发音（每个间隔 1～3 秒），**期间照常能用**，
> 只是刚导入时部分单词还没声音，等一会儿就有了。

## 7. 备份、迁移与卸载

### 备份（建议每月一次）

「数据管理」→ **「导出全部数据」** → 保存好生成的 `.json` 文件。

它包含：所有单词、词组结构、复习统计 —— **完整的一份数据**。

### 换电脑 / 重装系统

- **方法 A（推荐）**：新电脑上装好程序 → 打开「数据管理」→ **「导入备份数据」**
- **方法 B（整库搬家）**：关掉程序，把老电脑家目录下的 `worddb.mv.db` 拷到新电脑同样的位置

> `worddb.mv.db` 在哪：
> - **macOS**：`/Users/你的用户名/worddb.mv.db`（访达 → 前往 → 前往文件夹 → 输入 `~`）
> - **Windows**：`C:\Users\你的用户名\worddb.mv.db`

### 卸载

1. 关掉程序
2. 删除整个程序文件夹
3. 删除 `worddb.mv.db`（不删的话，下次装回来数据还在）

## 8. 常见问题速查表

### 🔴 启动相关

| 现象 | 原因 | 解决办法 |
|:--|:--|:--|
| 双击没任何反应 | 文件在压缩包里 / 没解压 | 先解压，再在解压后的文件夹里双击 |
| macOS 提示「无法打开，来自身份不明的开发者」 | 系统安全限制 | 右键 → 打开 → 再点打开（详见第 3 章） |
| Windows 蓝色「已保护你的电脑」 | SmartScreen 拦截 | 点「更多信息」→「仍要运行」 |
| 提示 **「没有找到 Java」** | 包里 `jre/` 被删了，或用的是不带 JRE 的包 | ① 确认 `jre` 文件夹还在；② 或装一次 Java：https://adoptium.net/temurin/releases/ |
| 提示 **「没有找到 WordReviewPro.jar」** | 文件夹不完整 | 重新解压一次 |
| 窗口一闪就没 / 直接报错 | 见下面「第 9 章」把日志发我 | 先看 `app.log` 最后几行 |
| 启动成功了，但浏览器**没自动打开** | 系统没配默认浏览器 | 手动访问 `http://localhost:8080` |
| 一直卡在「启动中……」 | 见下面几条 | 逐条排查 |

### 🟠 端口 / 数据库冲突（最常见！）

| 现象 | 原因 | 解决办法 |
|:--|:--|:--|
| 提示「端口 8080 已被占用」 | 程序已经开着，又双击了一次 | **直接访问 `http://localhost:8080` 即可**，或先关掉之前那个窗口 |
| 报错 **`The file is locked: worddb.mv.db`** 或 **`Database may be already in use`** | 同上：同一时间只能开一个实例 | 关掉所有已开的启动窗口，只留一个；或直接访问 `http://localhost:8080` |
| 提示「端口 8080 被占用」但**不是**本程序 | 8080 被别的软件占了 | 按 **[第 4 章](#4-怎么改端口可选)** 改个端口（如 8081），保存后重启程序 |
| 改了端口，页面打不开 / 浏览器一直转圈 | 浏览器地址还是旧端口 | 地址改成 `http://localhost:新端口号` |
| 改配置文件改坏了，起不来 | 格式不对 | 把那行改回 `server.port=8080`，注意等号前后别加空格 |
| 装了两份程序，数据不一致 | 两份各自带 `WordReviewPro.jar`，但**数据库只有一份**（在家目录） | 程序可以装多份，但同一时间只能开一个；数据是共用的，不会丢 |

> 💡 **一句话记住**：这个程序**一次只能开一个**。重复双击 = 报端口或数据库占用。

### 🟡 页面 / 显示相关

| 现象 | 原因 | 解决办法 |
|:--|:--|:--|
| 浏览器显示「无法访问此网站 / 连接被拒绝」 | 程序没在运行，或还在启动中 | 看启动窗口是否显示「✅ 启动成功」；没有就等它跑完 |
| 打开是**白屏**，或页面图标/样式错乱 | 浏览器缓存了旧文件 | 按 **`Ctrl + Shift + R`**（Windows）/ **`Cmd + Shift + R`**（macOS）强制刷新 |
| 地址栏随手改了路径后 404 | 正常现象 | 只用启动时的 `http://localhost:8080`，或从左侧菜单点进去 |
| 页面上没有我导入的单词 | ① 没导入成功；② 当前筛选的词组不对 | 去「词库管理」，把「按词组筛选」的下拉**清空**（点 × ）即为看全部 |
| 界面字太小 / 布局乱 | 程序按 **1920×1080 及以上**大屏设计 | 用外接大屏，或把浏览器窗口最大化并调浏览器缩放 |

### 🟢 导入 / 导出相关

| 现象 | 原因 | 解决办法 |
|:--|:--|:--|
| 导入按钮是灰的 / 提示要选词组 | **必须先选目标词组** | 页面上方先选词组，再选文件 |
| 提示导入失败 | Excel 列对不上 | 严格按 A～E：生词、音标、含义、例句、例句释义，第 1 行是标题 |
| 导入后一个都没进来 | 文件里没有数据行 | 先「导出 Excel」拿模板，照格式填 |
| 担心重复导入 | —— | 不用担心：同名单词只会更新内容，不会重复，复习记录保留 |
| 导出的 Excel 打不开 | 少见 | 换 Excel 或 WPS 打开；还不行把文件发我 |

### 🔵 发音相关

| 现象 | 原因 | 解决办法 |
|:--|:--|:--|
| 点 🔊 没声音 | 首次需要联网合成 | 确认有网，等几秒重试；生成后会缓存到本地，之后离线也能放 |
| 刚导入的单词没声音 | 后台还在批量生成 | 程序在生成中（每个 1～3 秒），等等就好 |
| 有声音但没自动播放 | 各阶段规则不同 | 默写阶段默认不自动播（提交后才播）；四个阶段都有 🔊 手动按钮 |
| 公司/校园网连不上微软 | 网络限制 | 换手机热点试一次，成功后会缓存，以后不用再联网 |

### ⚙️ 其他

| 现象 | 解决办法 |
|:--|:--|
| 关掉终端窗口，网页就打不开了 | 正常，程序随窗口关闭。重新双击启动即可 |
| 电脑重启后数据还在吗 | **在**。数据存在家目录 `worddb.mv.db`，重启不丢 |
| 程序是不是要联网 | 只有**第一次生成发音**需要网；其余全离线，数据也不上传 |
| 想删掉程序但保留数据 | 先「导出 JSON」备份，再删文件夹和 `worddb.mv.db` |

## 9. 还是搞不定？这样把问题发给我

按顺序做这 4 步，然后把**截图 + 文件**发我：

**① 找日志文件**（在程序文件夹里）

| 系统 | 日志文件 |
|:--|:--|
| macOS | `app.log` |
| Windows | `app-err.log` 和 `app-out.log` |

> 找不到？可以这样搜：
> - **macOS**：在程序文件夹里按 `Cmd + Shift + .` 显示隐藏文件，或直接打开「终端」输入 `ls` 看
> - **Windows**：在程序文件夹地址栏输入 `cmd` 回车，再输入 `dir` 看

**② 拍下启动窗口**（从双击到报错的完整画面）

**③ 告诉我**

- 你的系统：macOS 还是 Windows？版本多少？（Apple 芯片还是 Intel？）
- 你是**双击哪个文件**启动的？
- 报错的**完整文字**（拍照也行）

**④ 如果页面能打开，把浏览器地址栏发我**

## 附：开发者须知（普通用户跳过）

- 本说明面向**普通使用者**，不需要装任何开发工具
- 开发者用 `./dev.sh start`（前后端分离，访问 `http://localhost:5173`）
- 打包发布用 `./release.sh`，详见 `README.md` 的「📦 打包分发」章节
- 这两个环境**互相独立**，但**共用同一个数据库**，所以开发环境开着时发布包起不来（报数据库被占用），反之亦然
