📖 Word Review Pro 使用说明（速查版）
====================================

详细图文版见同目录的 README.md，遇到问题先看它。

这是一个本地单词复习工具，所有数据只存在你自己电脑上，不联网、不上传。


【怎么启动】
--------------------
macOS:
  双击「Start.command」
  第一次如果提示"无法打开，来自身份不明的开发者"：
    右键点击该文件 → 打开 → 再点「打开」
  或在终端执行:  ./start.sh

Windows:
  双击「start.bat」
  如果弹出蓝色的"Windows 已保护你的电脑"：
    点「更多信息」→「仍要运行」
  如果弹出防火墙提示：点「取消」即可，不影响本机使用

启动后会自动打开浏览器，访问 http://localhost:8080
看到页面就是成功了。没自动打开就手动在浏览器输入这个地址。

⚠ 只能开一个实例：重复双击会报"端口被占用"或"数据库被占用"，
  这时直接访问 http://localhost:8080 就行。
⚠ 启动窗口别关，关了程序就停了。


【怎么改端口（可选，默认 8080）】
--------------------
只有提示"端口 8080 已被占用"、而占用它的不是本程序时才需要改：
  1. 用记事本打开程序文件夹里的  application.properties
  2. 把最后一行  server.port=8080  改成  server.port=8081
  3. 保存 → 关掉程序 → 重新双击启动
  4. 浏览器地址也要改成  http://localhost:8081

注意：
  · 等号前后不要加空格，格式必须是  server.port=数字
  · 必须重启才生效
  · 改端口不会影响数据，worddb.mv.db 不受影响
  · 改坏了就改回  server.port=8080


【第一次用：导入单词】
--------------------
程序自带空词库，需要先导入：
  1. 左侧菜单「词组管理」→「➕ 新增根词组」（也可跳过，用自带的默认词组）
  2. 左侧菜单「数据管理」
  3. 在「导入到词组：」先选一个词组（必须先选，否则无法上传）
  4. 点击下方虚线框「将 Excel 文件拖到此处，或 点击上传」
  5. 选中文件后自动导入

Excel 格式（A-E 列，第 1 行是标题）:
  A 生词  B 音标  C 含义  D 例句  E 例句释义
  支持 .xls / .xlsx，空行自动跳过。

没现成的表？点「导出为 Excel」拿到格式正确的空模板，照着填。
重复导入同一个词只会更新内容，不会重复，也不会清空复习记录。

导入后去「复习中心」选模式开始背：
  完整复习（认读+拼写+默写） / 仅认读复习 / 仅拼写练习
  / 仅默写复习 / 仅听音默写


【数据存在哪里】
--------------------
单词数据（家目录，跟程序放哪无关）:
  macOS:   /Users/你的用户名/worddb.mv.db
  Windows: C:\Users\你的用户名\worddb.mv.db
音频缓存:  程序目录下的 audio/ 文件夹

备份:      「数据管理」→「导出全部数据」，得到 .json 文件
恢复/换电脑: 「数据管理」→「导入备份数据」


【注意事项】
--------------------
· 单词发音（🔊）首次播放需联网，向微软在线合成语音，
  生成后缓存到本地 audio/，之后离线也能放。
  刚导入大批单词时会在后台陆续生成（每个 1~3 秒），期间程序照常可用。
· 程序占用本机 8080 端口，同一时间只能开一个实例。
· 数据只存在本机，程序本身只在"生成发音"时需要联网。
· 页面白屏/样式错乱：按 Ctrl+Shift+R（Win）或 Cmd+Shift+R（Mac）强制刷新。
· 卸载 = 删除整个文件夹，再删掉家目录下的 worddb.mv.db 即可。


【常见问题】
--------------------
双击没反应？
  → 先解压，再在解压后的文件夹里双击（别在压缩包窗口里直接点）。

启动失败、窗口一闪而过？
  → 看程序目录下的 app.log（macOS）或 app-out.log / app-err.log（Windows），
    把最后几行发给发程序给你的人。详见 README.md 第 8 章。

提示「端口 8080 已被占用」或「数据库被占用 / Database may be already in use」？
  → 程序已经在运行了（可能重复双击了两次）。
    直接访问 http://localhost:8080；或先关掉之前的启动窗口再开。
    如果占用 8080 的是别的软件，按上面【怎么改端口】换个端口即可。

改了端口但页面打不开？
  → 浏览器地址里的端口号也要换成新的，比如 http://localhost:8081

提示「没有找到 WordReviewPro.jar」？
  → 文件夹不完整，重新解压一次。

提示「没有找到 Java」？
  → 包里 jre 文件夹被删了，或用的是不内置 Java 的包。
    把 jre 文件夹放回去；或装一次 Java 11 以上：
    https://adoptium.net/temurin/releases/

页面打不开 / 连接被拒绝？
  → 程序没在运行或还在启动中。看启动窗口是否已显示"✅ 启动成功"。

打开是白屏？
  → 浏览器缓存了旧文件，强制刷新（Ctrl+Shift+R / Cmd+Shift+R）。

导入没反应？
  → 必须先在「导入到词组：」选词组，否则上传框是禁用的。

导入后词库是空的？
  → 去「词库管理」，把「按词组筛选」的下拉清空（点 ×）看全部。

发音没声音？
  → 首次需要联网生成，等几秒重试；或刚导入还在后台生成中。
